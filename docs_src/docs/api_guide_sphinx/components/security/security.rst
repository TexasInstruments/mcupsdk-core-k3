Security
========

Introduction
------------

This page links to sub modules that enable data authentication, integrity and confidentiality.

Security on this device is ensured via the following features:

- **Cryptography Services**

  - :doc:`SA3UL <crypto/sa3ul>` (Ultra lite Security Accelerator) — Description of SA3UL architecture and APIs available to use AES, SHA and RNG engine.

APIs for Security Drivers
--------------------------

- :doc:`SA3UL <crypto/sa3ul>` — APIs for SA3UL Security Accelerator (AES, SHA, RNG)
- :doc:`Cryptography <crypto/crypto>` — APIs for Cryptographic operations
