# SBL Booting Linux From SD CARD
## Introduction


:::{only} SOC_AM62AX
   - SBL booting Linux from SD card (see [SBL SD LINUX](../examples/drivers/sbl_sd_linux.md)) is a secondary bootloader application that boots Linux on A53 core and RTOS/NORTOS application on R5, C7x cores.
   - The bootloader makes use of 5 appimages
       - A Linux appimage containing the **Linux binaries (ATF, OPTEE, A53 SPL)**.
       - tiboot3.bin with **SBL SD, TIFS, BoardConfig**
       - Appimage for **MCU R5**
       - Appimage for **C75**
       - Appimage for **DM R5**
:::


:::{only} SOC_AM62PX
   - SBL booting Linux from eMMC (see [EXAMPLES_DRIVERS_SBL_EMMC_LINUX_MULTISTAGE](../examples/drivers/sbl_emmc_linux_multistage.md)) is a secondary bootloader application that boots Linux on A53 core and RTOS/NORTOS application on R5 core.
   - The bootloader makes use of 4 appimages
       - A Linux appimage containing the **Linux binaries (ATF, OPTEE, A53 SPL)**.
       - tiboot3.bin with **SBL SD, TIFS, BoardConfig**
       - Appimage for **MCU R5**
       - Appimage for **WKUP R5**
:::

- The Linux appimage can be generated by using [Linux Appimage Generator Tool](../components/tools/tools_boot.md)
- The appimages will be copied to SD card, the SBL parses the appimages from the boot partition, loads and run the cores.

## SD Card Partitioning


:::{only} SOC_AM62AX
   - SD card uses two partitions to boot Linux
       - A boot partition
           - tiboot3.bin
           - mcu_r5_image
           - dm_r5_image
           - linux_a53_image
           - c7x_image
       - A ext4 partition in the user data area containing
           - Linux Kernel image
           - Linux DTB
           - Linux file system
:::


:::{only} SOC_AM62PX
   - SD card uses two partitions to boot Linux
       - A boot partition
           - tiboot3.bin
           - mcu_r5_image
           - wkup_r5_image
           - linux_a53_image
       - A ext4 partition in the user data area containing
           - Linux Kernel image
           - Linux DTB
           - Linux file system
:::
