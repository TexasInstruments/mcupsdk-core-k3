This page lists all the examples related to usage of SDL.

The Software Diagnostics Library (SDL) provides interfaces to hardware safety mechanisms
and features of the SoC. SDL assists in the development of software applications involving
Functional Safety by enabling detection of random hardware faults and supporting appropriate
system responses.
