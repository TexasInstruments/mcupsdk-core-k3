# Ethernet Autoamplifier with CRF Demo

## Introduction

::::{only} SOC_AM62DX
:::{note}
This example supports the AM62D-EVM-PROC180E2. To test with the AM62D-EVM-PROC180E1, change the phy addresses in TI BOARD DRIVERS -> ETHPHY -> CONFIG_ENET_ETHPHY(x) -> phy Address to 15 and 3.
:::
::::

This example illustrates the configuration and usage of Multistream AAF PCM Talker/Listener along with CRF Talker/Listener using IEEE Std 1722™-2016 stack and TCP Echo server running on LwIP with CPSW Peripheral.

This example also runs IEEE802.AS protocol in the background where the PHY(DP83TG721) timestamps the Egress,Ingress gPTP packets and also maintains the gPTP Clock. The IEEE802.1AS Stack receives the timestamps of the gPTP Packets and adjusts the gPTP Clock in PHY through MDIO.

DMA Channel Configuration:

DMA Channel Index      |      Purpose
-----------------------|---------------
Channel 0              | Background Traffic, Non Realtime Traffic (TCP Server)
Channel 1              | gPTP Traffic
Channel 2              | AVTP and CRF Packets

- Two {{ VAR_BOARD_NAME_LOWER }} boards with one dp83tg721 add-on card for each {{ VAR_BOARD_NAME_LOWER }}

## Steps to Run the Example

### Build the example

Refer [Enet CPSW TSN gPTP Examples](enet_cpsw_tsn_gptp.md) to build the avtp examples.

### HW Setup

:::{figure} ../../images/examples/autoampdemo_setup.png
Autoamp Demo Hardware Setup
:::

### Run the example

:::{attention}
If you need to reload and run again, a CPU power-cycle is MUST
:::

- Connect two {{ VAR_BOARD_NAME_LOWER }} boards from MacPort1 to MacPort1 like shown in the above image.
- Load the examples to both the DUTs and click on Run.
- Look for the "INF:avtp:CRF talker 00:01:02:03:04:05:00:04:pdus/sec=49 freq_Hz=48000 ts_interval=160" print in the CRF Listener logs, this confirms the generation of CRF Frames by CRF Talker.
- Look for the "INF:avtp:[RX=y] Packet Count: XXXXX" print on both the DUTs to verify packet reception of the AVTP Packets.
- The Media clock generated by the DP83TG721 phy, can be measured on the TP10 testpoint of the add-on card of both the DUTs.

:::{note}
The CRF Listener is a sample application that receives the CRF Frames and performing Media Clock Recovery is out of scope of this demo.
:::
